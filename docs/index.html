Fast by design

03

Quiet software

No accounts, analytics, update pings, or history database. Preferences and the last reading session are saved locally on normal exit.

Network behavior

Your document stays yours.

Local documents are not uploaded. FastMarkdownViewer has no telemetry or update checker and does not execute HTML.

Visible remote images load automatically by default. Turn this off in Settings to load images individually. Image caches stay in memory and worker concurrency is bounded. That request exposes your IP to the image host, but sends no cookies, credentials, or referrer. Responses, redirects, formats, and decoded dimensions are bounded.

Verify a download

Trust the build trail.

  1. Download togetherGet your platform package and SHA256SUMS.txt from the same canonical GitHub Release.
  2. Compare SHA-256Get-FileHash .\FastMarkdownViewer-0.2.5-windows-x86_64.exe -Algorithm SHA256
  3. Verify provenancegh attestation verify .\FastMarkdownViewer-0.2.5-windows-x86_64.exe --repo {{REPOSITORY_SLUG}}

Checksums and attestations establish origin and unchanged bytes. They do not suppress Windows SmartScreen or macOS downloaded-app security checks.

After v0.1

Stability first. Reach second.

Windows x64, macOS 15+ for Apple Silicon and Intel, and Ubuntu 24.04 x64 are supported. Future work can include code signing, Windows ARM64, high-contrast design, and package-manager listings. Tabs, wildcard search, a heading outline, and lazy syntax highlighting are included. Offline Mermaid rendering is included with resource limits and source fallback; editing and file watching remain outside this release.
