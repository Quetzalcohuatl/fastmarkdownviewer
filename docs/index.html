Network behavior

Your document stays yours.

Local documents are not uploaded. FastMarkdownViewer has no telemetry or update checker and does not execute HTML.

Visible remote images load automatically in memory. That request exposes your IP to the image host, but sends no cookies, credentials, or referrer. Responses, redirects, formats, and decoded dimensions are bounded.

Verify a download

Trust the build trail.

  1. Download togetherGet the EXE or ZIP and SHA256SUMS.txt from the same canonical GitHub Release.
  2. Compare SHA-256Get-FileHash .\FastMarkdownViewer-0.1.0-alpha.1-windows-x86_64.exe -Algorithm SHA256
  3. Verify provenancegh attestation verify .\FastMarkdownViewer-0.1.0-alpha.1-windows-x86_64.exe --repo {{REPOSITORY_SLUG}}

Checksums and attestations establish origin and unchanged bytes. They do not suppress SmartScreen; v0.1.0-alpha.1 is transparently unsigned.
