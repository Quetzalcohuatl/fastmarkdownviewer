# Security policy

## Supported versions

Until v0.1.0 is released, only the latest `main` branch is supported. After release, the newest stable release and `main` receive security fixes.

## Reporting a vulnerability

Please use GitHub's private **Security advisories → Report a vulnerability** flow. Do not open a public issue for a suspected vulnerability. Include affected versions, reproduction steps, impact, and any suggested mitigation. The maintainers will acknowledge a complete report within seven days and will coordinate disclosure after a fix is available.

Particularly relevant areas include URL/scheme handling, redirects, remote-image limits, path resolution, unsafe HTML behavior, installer registry cleanup, and release provenance.

The project never requests Markdown files, credentials, telemetry, or crash dumps from users automatically.
